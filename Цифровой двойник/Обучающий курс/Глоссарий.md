# Глоссарий курса «Цифровой двойник»

Термины курса с краткими определениями и указанием темы, где термин раскрывается подробно. Определения даны в объёме, достаточном для работы над [итоговым проектом](Итоговый%20проект.md); формальные формулировки см. в стандартах, перечисленных в конце.

## Основные понятия

| Термин | Определение | Где раскрыт |
|--------|-------------|-------------|
| Цифровой двойник (digital twin, DT) | Виртуальное представление объекта или процесса, связанное с оригиналом потоком данных и используемое для анализа, прогноза и поддержки решений | Модуль 1, тема 1 |
| Цифровая модель (digital model) | Виртуальное представление без автоматической связи с оригиналом: данные переносятся вручную | Модуль 1, тема 1 |
| Цифровая тень (digital shadow) | Виртуальное представление с автоматическим односторонним потоком данных от объекта к модели | Модуль 1, тема 1 |
| Симуляция | Расчёт поведения модели при заданных условиях; составная часть двойника, но не двойник сама по себе | Модуль 1, тема 1 |
| Уровень зрелости DT | Характеристика возможностей двойника: от описания и мониторинга до предиктивных, предписывающих и автономных функций | Модуль 1, тема 2 |
| Жизненный цикл изделия | Последовательность этапов от замысла и проектирования до эксплуатации, модернизации и вывода из эксплуатации | Модуль 1, тема 3 |
| Цифровая нить (digital thread) | Сквозная прослеживаемая связь данных об объекте на всех этапах жизненного цикла | Модуль 1, тема 3 |
| Конфигурации as-designed / as-built / as-maintained | Состояния объекта по проекту, по факту изготовления и по факту обслуживания | Модуль 1, тема 3 |
| Двойник изделия, процесса, производства, бизнес-процесса | Типы двойников, различающиеся объектом моделирования, источниками данных и метриками | Модуль 1, тема 4 |
| Система систем | Композиция двойников нижнего уровня в двойник более крупного объекта — предприятия, отрасли, территории | Модуль 1, тема 4 |

## Экономика и управление

| Термин | Определение | Где раскрыт |
|--------|-------------|-------------|
| Источники ценности DT | Направления получения эффекта: простои, качество, энергия, запасы, безопасность, ресурс, скорость решений | Модуль 1, тема 5 |
| TCO (совокупная стоимость владения) | Полные затраты на двойник за срок жизни: данные, интеграция, моделирование, инфраструктура, поддержка, обучение | Модуль 1, тема 5 |
| ROI и срок окупаемости | Отношение эффекта к затратам и время возврата вложений | Модуль 1, тема 5 |
| Портфель DT-инициатив | Набор инициатив, разделённый на пилоты, масштабируемые решения и платформенные элементы | Модуль 4, тема 1 |
| Pilot purgatory | Состояние, когда пилоты множатся, но ни один не переходит в промышленную эксплуатацию | Модуль 4, тема 1 |
| Вендор-лок | Зависимость от поставщика, при которой смена платформы требует несоразмерных затрат | Модуль 4, тема 2 |
| Дорожная карта внедрения | План перехода от оценки готовности к пилоту, промышленной эксплуатации и масштабированию с метриками по горизонтам | Модуль 4, тема 1 |

## Архитектура и данные

| Термин | Определение | Где раскрыт |
|--------|-------------|-------------|
| Слоистая архитектура DT | Разделение системы на слои: источники, сбор и транспорт, хранение, модели, сервисы, представление, сквозные функции | Модуль 2, тема 1 |
| Edge-вычисления | Обработка данных вблизи источника до их передачи в централизованные системы | Модуль 2, тема 1 |
| Восходящий и нисходящий потоки | Телеметрия от объекта к двойнику и команды, уставки или рекомендации в обратном направлении | Модуль 2, тема 1 |
| IIoT | Промышленный интернет вещей: датчики и устройства, передающие данные в информационные системы | Модуль 2, тема 2 |
| SCADA | Система диспетчерского управления и сбора данных технологического процесса | Модуль 2, тема 2 |
| MES | Система управления производственными процессами на уровне цеха | Модуль 2, тема 2 |
| ERP | Система планирования ресурсов предприятия | Модуль 2, тема 2 |
| НСИ (мастер-данные) | Нормативно-справочная информация: справочники объектов, классификаторы, иерархии активов | Модуль 2, тема 6 |
| Качество данных | Совокупность свойств: полнота, точность, своевременность, согласованность, уникальность | Модуль 2, тема 2 |
| Дрейф датчика | Постепенное смещение показаний измерительного прибора относительно истинного значения | Модуль 2, тема 2 |
| OPC UA | Промышленный стандарт обмена данными с информационной моделью и механизмами безопасности | Модуль 2, тема 3 |
| MQTT | Лёгкий протокол обмена сообщениями по модели «издатель — подписчик» | Модуль 2, тема 3 |
| Частота синхронизации | Периодичность обновления данных двойника, выбираемая исходя из постоянной времени объекта и задачи сценария | Модуль 2, тема 3 |
| Идемпотентность | Свойство операции давать одинаковый результат при повторной обработке одного и того же сообщения | Модуль 2, тема 3 |
| Однонаправленный шлюз (data diode) | Средство передачи данных строго в одну сторону, применяемое между контурами разной защищённости | Модуль 2, тема 3; Модуль 3, тема 7 |
| ROM (редуцированная модель) | Упрощённая модель, воспроизводящая поведение подробной модели с приемлемой точностью и меньшими затратами на расчёт | Модуль 2, тема 4; Модуль 3, тема 3 |
| Суррогатная модель | Быстрая аппроксимация дорогой расчётной модели, обученная на её результатах | Модуль 2, тема 4 |
| Онтология | Формальное описание понятий предметной области и связей между ними | Модуль 2, тема 4 |
| Матрица требований | Таблица связи бизнес-вопросов с данными, моделями, точностью, частотой и потребителями результата | Модуль 2, тема 5 |
| Паспорт сценария расчёта | Описание входов, допущений, ограничений, выходов и критериев валидности расчёта | Модуль 2, тема 5 |
| Медальонная архитектура | Организация данных по слоям обработки: сырые, очищенные, витринные | Модуль 2, тема 6 |
| Происхождение данных (lineage) | Прослеживаемая история происхождения и преобразований данных | Модуль 2, тема 6 |
| Time series хранилище | Хранилище, оптимизированное под временные ряды измерений | Модуль 2, тема 6 |

## Аналитика и эксплуатация

| Термин | Определение | Где раскрыт |
|--------|-------------|-------------|
| What-if анализ | Сравнение вариантов решения путём расчёта модели при изменённых условиях | Модуль 3, тема 1 |
| Анализ чувствительности | Оценка влияния изменения входных параметров на результат расчёта | Модуль 3, тема 1 |
| Калибровка модели | Подбор параметров модели так, чтобы её выход соответствовал фактическим данным | Модуль 3, тема 1 |
| Метод Монте-Карло | Многократный расчёт модели со случайными значениями входов для оценки распределения результата | Модуль 3, тема 1 |
| Аномалия | Наблюдение, существенно отклоняющееся от ожидаемого поведения объекта | Модуль 3, тема 2 |
| Остаточный ресурс (RUL) | Прогнозируемое время до достижения объектом предельного состояния | Модуль 3, тема 2 |
| Предиктивное обслуживание | Стратегия обслуживания по прогнозу состояния, а не по календарю или наработке | Модуль 3, тема 2 |
| FMEA | Анализ видов и последствий отказов | Модуль 3, тема 2 |
| Гибридный DT | Двойник, сочетающий физико-математические модели и модели, обученные на данных | Модуль 3, тема 3 |
| PINN | Нейросеть, обучаемая с учётом физических уравнений задачи | Модуль 3, тема 3 |
| Дрейф данных | Изменение статистических свойств входных данных относительно тех, на которых модель обучалась | Модуль 3, тема 3 |
| MLOps | Практики управления жизненным циклом моделей: версии, развёртывание, мониторинг, переобучение | Модуль 3, тема 3 |
| Шум алармов | Избыток малозначимых оповещений, из-за которого оператор перестаёт реагировать на важные | Модуль 3, тема 4 |
| Уровень автономности | Степень участия человека: информирование, рекомендация, подтверждение, автоматическое исполнение | Модуль 3, тема 5 |
| Замкнутый контур (closed loop) | Схема, в которой результат расчёта двойника автоматически влияет на управление объектом | Модуль 3, тема 5 |
| MPC | Управление с прогнозирующей моделью | Модуль 3, тема 5 |
| Human-in-the-loop | Схема, при которой решение утверждается человеком | Модуль 3, тема 5 |
| Верификация и валидация | Проверка правильности реализации модели и её соответствия реальному объекту | Модуль 3, тема 6 |
| Границы применимости | Диапазоны входов и условия эксплуатации, в которых модель признана достоверной | Модуль 3, тема 6 |
| Алеаторная и эпистемическая неопределённость | Неопределённость из-за естественной изменчивости и из-за недостатка знаний | Модуль 3, тема 6 |
| Паспорт модели (model card) | Документ с назначением, данными, метриками, ограничениями и владельцем модели | Модуль 3, тема 6 |
| Модель угроз | Систематизированное описание источников угроз, объектов защиты и возможных сценариев атак | Модуль 3, тема 7 |
| Агрегационный риск | Риск получения чувствительного результата из совокупности отдельно несекретных данных | Модуль 3, тема 7 |
| Отравление данных | Целенаправленное искажение обучающих данных для порчи модели | Модуль 3, тема 7 |
| Сегментация зон и каналов | Разделение сети и систем на зоны с контролируемыми каналами связи между ними | Модуль 3, тема 7 |
| RBAC / ABAC | Управление доступом на основе ролей и на основе атрибутов | Модуль 3, тема 7 |
